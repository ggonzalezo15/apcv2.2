## 🚀 Instalación Rápida

### Paso 1: Instalar GD
```bash
# Para XAMPP Windows:
# 1. Abrir C:\xampp\php\php.ini
# 2. Cambiar ;extension=gd a extension=gd
# 3. Reiniciar Apache

# Para Linux:
sudo apt install php-gd
sudo systemctl restart apache2
```

### Paso 2: Usar Sistema Completo
1. Acceder a `simple_test_complete.php`
2. Tab "Configuración" → "Configurar Sistema"
3. Verificar dependencias y conexión B2
4. Tab "Upload" → Seleccionar año → Subir archivos
5. Tab "Viewer" → Ver y gestionar attachments
